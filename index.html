Key Advantages & Features

⚡

Real-Time XML Interception

Automatically hooks into the native onContentPrepareForm event to rewrite form XML elements in-memory before they are rendered.

💎

JCE global Upgrade

Converts both core and third-party media fields instantly. Say goodbye to basic media fields and hello to folder limits, resizing, and filters!

🛡️

100% Upgrade-Safe

Zero modifications to physical database schemas, Core Joomla modules, or third-party layouts. Fully safe from core updates.

📦

Modern Architecture

Fully architected using native Joomla 6 service providers, modern Dependency Injection (DIC), and strictly compliant namespaces.

🌍

Multilingual Translations

Natively localized for full internationalization with built-in translations for both English (en-GB) and Portuguese (pt-BR).

🔌

Zero Configuration

Just install, enable in Joomla's Plugin Manager, and watch all your fields instantly morph into powerful JCE browsers.
